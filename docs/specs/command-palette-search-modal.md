# Specification: Command Palette / Spotlight Search Modal (Ctrl+K Overlay)

## 1. Context & User Story
The search interface on [arunsr.in](https://www.arunsr.in) currently renders search results inside a small absolute-positioned dropdown beneath the header search input. As the digital garden expands across tech notes, book reviews, game analysis, and research topics, visitors need a modern, centered Command Palette (Raycast / Algolia DocSearch / Spotlight style) for rapid discovery and keyboard-driven navigation.

As a visitor exploring arunsrin's digital garden, I want a centered Command Palette modal triggered by `Ctrl+K`, `Cmd+K`, `/`, or clicking the header search bar, so that I can:
- Quickly search note titles, content, and tags with real-time relevance scoring and term highlighting.
- Instantly filter tags by prefixing the search query with `#` (e.g. `#mon` -> `monitoring`), browsing tags with note counts and directly navigating to `/tags/<tag>/` or filtering notes in-modal.
- Identify the section of each result at a glance via visual category chips (e.g. 💻 Tech, 📚 Books, 🎮 Games, 🔬 Research, 📝 Posts).
- Navigate effortlessly using keyboard shortcuts (`↑` / `↓` to select, `Enter` to open, `Escape` to close).
- Enjoy an aesthetic, theme-consistent backdrop blur experience on both desktop and mobile devices.

---

## 2. Author Decisions (Phase 1 Scoping)
During the Phase 1 interview and requirement review, the author confirmed:
1. **Header Trigger**: Clicking the header search bar or pressing `Ctrl+K` / `Cmd+K` / `/` opens the centered Command Palette modal with the modal's input auto-focused.
2. **Tag Filtering (`#` prefix)**: Hybrid behavior:
   - Prefixing the query with `#` (e.g. `#m`, `#mon`) shows matching tags with note counts first. Pressing `Enter` or clicking a tag navigates to `/tags/<tag>/`.
   - Pressing `Tab` on a highlighted tag or typing `#tag ` (e.g. `#linux `) filters and lists notes possessing that tag right in the modal.
3. **Visual Category Chips**: Results display clean category chips based on URL path:
   - `/tech/...` -> `💻 Tech`
   - `/books/...` -> `📚 Books`
   - `/games/...` -> `🎮 Games`
   - `/other-interests/...` -> `🔬 Research`
   - `/posts/...` -> `📝 Posts`
   - `/tags/...` -> `🏷️ Tag`
   - Fallback -> `📄 Note`
4. **Theme Consistency**: Frosted glass backdrop blur (`backdrop-filter: blur(8px)`) with light blue accent borders (`#0284c7` in light mode, `#38bdf8` in dark mode).

## 3. Core Guardrails (AGENTS.md Compliance)
- **Sacred Prose (Rule 9)**: No markdown prose or note text may be rewritten or altered.
- **Performance & Zero Bloat (Rule 1)**: Pure vanilla JavaScript (<3 KB), zero external dependencies or heavy search frameworks.
- **Cloudflare Rocket Loader Safety (Rule 2)**: ZERO inline event handlers (`onclick`, `onkeydown`, `oninput`). All event listeners attached unobtrusively via `addEventListener` after DOM load.
- **Visual Identity (Rule 1)**: Turquoise-to-sky-blue header accent and signature light-blue theme variables (`--link-color`, `--card-bg`, `--border-color`).
- **Stacking Contexts (Rule 13)**: The modal dialog is placed at the root level of the header/body with high z-index (`z-index: 1300`), leaving `.layout-container` at `z-index: auto`.
- **Automated Regression Testing & CI Parity (Rules 10 & 11)**: Dedicated automated test suite in `scripts/` verifying modal structure, zero inline handlers, category resolution, `#` tag filtering logic, and keyboard accessibility.
- **Windows UTF-8 Stdout Reconfiguration (Rule 12)**: All companion Python test scripts must include standard UTF-8 stdout reconfiguration.
- **Minified HTML Assertion Robustness (Rule 14)**: Regex assertions must tolerate optional quotes generated by `hugo --minify`.

## 4. Numbered Acceptance Criteria

1. **Header Trigger & Keyboard Shortcuts**:
   - The header search input/bar acts as a trigger button displaying `Search notes...` and shortcut badges (`Ctrl K` / `/`).
   - Pressing `Ctrl+K`, `Cmd+K`, or `/` (when not inside another input/textarea) opens the Command Palette modal and focuses the modal search input.
   - Clicking the header trigger opens the Command Palette modal and focuses the modal search input.
2. **Centered Modal UI & Backdrop Blur**:
   - The modal is rendered in a centered dialog container over a frosted glass backdrop overlay (`backdrop-filter: blur(...)`).
   - Modal header features a search icon, prominent search input (`#modal-search-input`), and an `ESC` badge.
   - Modal footer provides keyboard guidance shortcuts (`↑↓ Navigate`, `↵ Open`, `ESC Close`, `Prefix # for tags`).
   - Backdrop click outside modal container closes the modal.
   - Body scroll is locked when modal is open (`overflow: hidden`) and restored upon close.
3. **Full-Text Search Relevance & Result Formatting**:
   - Retains exact title, slug, tag, and content relevance scoring matching existing search accuracy.
   - Query term matches are highlighted inside `<mark class="search-highlight">` in both titles and snippet previews.
   - Each result card displays a category chip (e.g. `💻 Tech`, `📚 Books`, `🎮 Games`, `🔬 Research`, `📝 Posts`, `📄 Note`) beside the title.
   - Snippet cleaning strips icon shortcodes and leading markdown hashes.
4. **Tag Filtering with `#` Prefix**:
   - When the search query begins with `#` (e.g. `#m`, `#mon`, `#linux`):
     - Displays matching tags with tag icon `🏷️`, tag name, and note count (e.g. `🏷️ monitoring (5 notes)`).
     - Arrow navigation (`↑`/`↓`) and `Enter` (or click) on a tag navigates to `/tags/<tag>/`.
     - Pressing `Tab` autocompletes the search input with `#<tag> `.
     - If the query has `#<tag> ` (e.g. `#linux k8s` or `#monitoring `), the modal filters and displays notes that possess the specified tag, optionally filtering by additional query words.
5. **Keyboard Navigation & Accessibility**:
   - `ArrowDown` moves active selection to the next item; `ArrowUp` moves to the previous item (with visual `.search-item-selected` state and automatic scrolling into view).
   - `Enter` navigates to the currently highlighted item (or top result if none explicitly focused).
   - `Escape` closes the modal and returns focus cleanly.
   - ARIA roles: modal backdrop uses `role="dialog"`, `aria-modal="true"`, and `aria-label="Command Palette"`.
6. **Mobile Viewport Optimization**:
   - On screens `<= 640px`, the modal adapts seamlessly to 95vw width, comfortable touch targets, and proper keyboard offset.
7. **Zero Inline Event Handlers**:
   - 100% Rocket Loader safe: no `onclick`, `onkeydown`, `oninput`, or `onchange` inline attributes in generated HTML.
8. **Automated Regression Test Suite & CI Parity**:
   - Regression test script (e.g. `scripts/test_search_modal.js` and `scripts/test_search.js`) validates:
     - Modal backdrop and dialog DOM presence in generated HTML.
     - Zero inline handlers.
     - Tag prefix filter logic and tag extraction from search index.
     - Category resolution logic for paths across sections.
     - Complete test suite passes with exit code 0 under `./scripts/test.ps1` and `./scripts/test.sh`.
